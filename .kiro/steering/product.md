# Git Info Viewer

A Java Swing desktop application for viewing and managing Git repository information.

## Core Features

- **Repository Browser**: Directory tree navigation with automatic Git repository detection
- **Git Information Display**: Shows remotes, branches, commit history, and file changes
- **Branch Management**: Switch branches, pull updates, and perform batch operations across multiple repositories
- **GitLab Integration**: Fetch and clone projects from GitLab groups using API
- **Cherry-Pick Support**: Cherry-pick commits between repositories with conflict detection
- **File Search**: Search for files across repository directories
- **Commit History**: View detailed commit logs with file diffs
- **Batch Operations**: Perform operations on multiple selected repositories simultaneously

## Target Users

Developers managing multiple Git repositories who need a visual tool to:
- View repository status at a glance
- Perform batch branch switches across multiple repos
- Search commit history and file changes
- Integrate with GitLab for project management
