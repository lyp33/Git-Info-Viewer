===============================================
  如何在任务管理器显示应用名称？
===============================================

【问题】
任务管理器只显示"Java(TM) Platform SE binary"
无法快速识别Git Info Viewer

【推荐解决方案】使用Launch4j ⭐⭐⭐⭐⭐

1. 下载Launch4j
   网址：https://launch4j.sourceforge.net/

2. 打开Launch4j

3. 加载配置文件
   File -> Load Config -> 选择 launch4j-config.xml

4. 生成EXE
   点击"Build wrapper"按钮
   生成：Git-Info-Viewer.exe

5. 运行
   双击 Git-Info-Viewer.exe

【效果】
任务管理器显示：Git Info Viewer ✅
而不是：Java(TM) Platform SE binary ❌

【临时方案】使用启动脚本

如果暂时不想安装Launch4j，可以使用：

方法1：带控制台窗口
  start-git-viewer.bat

方法2：无控制台窗口
  run-git-viewer.bat

注意：这种方法任务管理器仍显示Java，
但窗口标题会显示"Git Info Viewer"

【Launch4j的额外好处】

✅ 自定义应用图标
✅ 看起来像原生Windows应用
✅ 可以设置启动画面
✅ 可以防止多次启动
✅ 用户不需要知道是Java应用
✅ 双击exe直接运行

【文件说明】

launch4j-config.xml - Launch4j配置文件
start-git-viewer.bat - 带控制台启动脚本
run-git-viewer.bat - 无控制台启动脚本
TASK_MANAGER_DISPLAY_NAME.md - 详细说明文档
